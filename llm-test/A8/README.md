## How to run the Notebook
- Have `Spotify_legal.txt` ready in the same directory of your notebook. It serves as a document for RAG.
- Install the dependencies according to `requirements.txt` (Note: we run our notebook in Google Colab.)
- Click run all.

---

## What you will get after running
- `rag_experiment_results.json`, which is the corresponding `all_results` from the notebook in json format.
- `rag_experiment_results.csv`, which is the corresponding `all_results` from the notebook in csv format.
Note that we include these two files for your reference in our submission.
